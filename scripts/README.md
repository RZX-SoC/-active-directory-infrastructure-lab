# Scripts

This directory will contain PowerShell or Command Prompt scripts created during the evolution of the laboratory.

Examples of future automation:

* User creation
* Security group creation
* Organizational Unit creation
* GPO configuration
* System information collection
* Event log collection
* Infrastructure validation

Scripts will be documented before being added to the repository.

## Security

Never store:

* Passwords
* API keys
* Tokens
* Private keys
* Production credentials

inside scripts committed to this repository.
